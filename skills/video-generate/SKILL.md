# Video Generate Skill

## 工具说明

**工具**: `video_generate_tool`（`tools.generationTools.generationTools`）

对视频进行编辑或纯生成，支持单视频/多视频参考与多图参考，通过 `generate_prompt` 描述期望效果，可引用占位符。

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `video_path` | `str` / `List[str]` / `None` | 否 | 待编辑视频路径。单路径、路径列表或空（纯生成）。多视频时在提示词中用 [视频1]、[视频2] 引用。 |
| `image_paths` | `List[str]` | 否 | 参考图路径列表，可为空。在提示词中用 [图1]、[图2] 引用。 |
| `generate_prompt` | `str` | 是 | 生成/编辑指令，描述风格、替换、移除、续写等；可引用 [图N]、[视频N]。 |
| `segment_id` | `int \| None` | 否 | 片段 ID，用于输出命名（如 `_seg{id}_edited`）。 |
| `video_ratio` | `str` | 否 | 输出比例，默认 `"16:9"`。可选：`"16:9"`,`"9:16"`,`"1:1"`,`"4:3"`,`"3:4"`,`"21:9"`。 |
| `video_resolution` | `str` | 否 | 输出分辨率，默认 `"480p"`。可选：`480p`,`720p`。 |
| `save_path` | `str \| None` | 否 | 输出路径。默认：有参考视频时为「原路径_seg{id}_edited」；无参考时为 `generated_seg{id}_edited.mp4`。 |
| `target_duration_s` | `float \| None` | 否 | 目标时长（秒）。无参考视频时必填；有参考时为空则与输入同长。不足 4s 会先按 4s 生成再裁剪。 |

### 返回值

`(video_path, first_frame_path, last_frame_path)`：输出视频路径、首帧图路径、尾帧图路径。

## 一、视频部分参考（11 种）

在 `generate_prompt` 中明确说明「参考」什么，并配合 `video_path` / `image_paths` 使用 [视频1]/[图1] 等占位符。

| 用法 | 说明 | 提示词示例 |
|------|------|------------|
| **参考主体** | 用参考视频/图中的主体形象 | 「保持 [视频1] 中的人物形象与服装，只改变背景和动作。」 |
| **参考背景** | 用参考中的场景/环境 | 「用 [图1] 的背景与光线，把 [视频1] 里的人物合成进去。」 |
| **参考构图** | 参考画面构图与景别 | 「按照 [视频1] 的构图和景别（如居中、三分法），重新生成相同构图的画面。」 |
| **参考风格** | 参考视觉/画风 | 「将 [视频1] 转为 [图1] 的插画/赛博朋克/水墨风格。」 |
| **参考运镜方式** | 参考镜头运动 | 「保持 [视频1] 的推拉摇移和运镜节奏，替换为新的场景和人物。」 |
| **参考运动轨迹** | 参考物体运动路径 | 「让角色按照 [视频1] 中物体的运动轨迹移动。」 |
| **参考台词** | 参考对白/字幕内容 | 「保留 [视频1] 的台词与口型，只更换说话人的外观。」 |
| **参考音效** | 参考声音设计（若模型支持） | 「保持 [视频1] 的节奏与音效风格，替换画面内容。」 |
| **视频转绘** | 用新风格重绘整段视频 | 「将 [视频1] 转绘成 [图1] 的二次元/像素风，保持动作一致。」 |
| **参考镜头角度** | 参考机位与视角 | 「用 [视频1] 的俯拍/仰拍/过肩角度，生成新场景。」 |
| **参考剪辑转场风格** | 参考切镜与转场 | 「延续 [视频1] 的剪辑节奏和转场方式，生成下一段镜头。」 |

## 二、视频元素编辑（8 种）

在 `generate_prompt` 中写清「改什么、改成什么样」，必要时用 [图N]/[视频N] 指定参考。

| 用法 | 说明 | 提示词示例 |
|------|------|------------|
| **修改主体** | 改人物/角色外观或身份 | 「把视频里的主角换成 [图1] 中的人物，保持动作不变。」 |
| **修改主体音色** | 改配音/音色（若支持） | 「保持画面与口型，将旁白改为成熟男声/女声。」 |
| **替换物品** | 替换画面中的物体 | 「将手中的手机替换成 [图1] 里的书本，其余不变。」 |
| **增加元素** | 在画面中增加物体或角色 | 「在画面左侧增加一只 [图1] 中的猫，自然融入场景。」 |
| **删减元素** | 移除不需要的物体/人物 | 「移除画面中所有的路人，只保留主角。」 |
| **背景修改** | 改场景/环境 | 「把背景换成 [图1] 的街道/森林，人物不变。」 |
| **镜头视角（运镜）修改** | 改机位或运动方式 | 「把固定镜头改成缓慢推进/环绕主角的运镜。」 |
| **台词修改** | 改对白/字幕 | 「把角色说的「你好」改成「再见」，口型与节奏尽量匹配。」 |

## 三、视频剧情续写和补全（3 种）

续写/补全时通常用前一段视频的尾帧或整段视频作为参考，并在 `generate_prompt` 中说明时间方向与内容。

| 用法 | 说明 | 提示词示例 |
|------|------|------------|
| **向前续写** | 生成当前片段「之前」的内容 | 「根据 [视频1] 的开头，续写此前 5 秒发生的事，保持风格与人物一致。」 |
| **向后续写** | 生成当前片段「之后」的内容 | 「以 [视频1] 的结尾为起点，向后续写 5 秒，动作与剧情自然衔接。」 |
| **剪辑过渡补全** | 在两段之间补过渡镜头 | 「在 [视频1] 结尾与 [视频2] 开头之间，生成 3 秒过渡镜头，使剪辑更流畅。」 |

多段时：`video_path=[前段路径, 后段路径]`，在提示词中用 [视频1]、[视频2] 引用；需要固定时长时设置 `target_duration_s`。

## 四、视频元素感知（6 种）

在 `generate_prompt` 中明确写出「做什么处理」，例如增强、分割、修复等。

| 用法 | 说明 | 提示词示例 |
|------|------|------------|
| **边缘检测** | 强调或利用边缘信息 | 「对画面做边缘检测风格化，突出轮廓线。」 |
| **元素分割** | 区分主体与背景等 | 「将人物与背景分离，保持人物清晰、背景可替换。」 |
| **关键点定位** | 突出关键点/骨架（若模型支持） | 「在人物上标出关键点/骨架，便于后续动作迁移。」 |
| **视频整体增强** | 去噪、提清晰度、低光增强 | 「对视频做去噪、去糊、低光增强，整体画质提升，保持原内容不变。」 |
| **联合捆绑搜索** | 多条件联合约束（用多图/多视频） | 「同时参考 [图1] 人物、[图2] 场景、[视频1] 动作，生成满足三者的一镜。」 |
| **局部修复** | 去掠影、去模糊、局部清晰化 | 「修复画面中的模糊区域和阴影，使局部更清晰。」 |

## 使用要点

1. **占位符**：有多个输入时，在 `generate_prompt` 中用 [图1]、[图2]、[视频1]、[视频2] 等与 `image_paths`、`video_path` 顺序一致。
2. **纯生成**：`video_path=None` 或 `[]` 时表示无参考视频，必须传 `target_duration_s`。
3. **时长**：API 要求参考视频 ≥2s、输出 ≥4s；工具会自动扩展/裁剪，对外按 `target_duration_s` 或输入时长输出。
4. **输出命名**：不传 `save_path` 时由 `segment_id` 和是否有参考视频决定输出文件名，便于多片段流水线使用。
